Storefront 1.2.0 · how to install and use it

Storefront puts all of Lennox's free Mac apps in one place. Install any of them in a click, and keep them all up to date from the menu bar.

What's in this folder

  • Storefront.app: the app
  • Install Storefront.command: installs it (run this)
  • Read Me.txt: this file

Before you start

  • Any Mac (Apple Silicon or Intel) running macOS 14 or later.

Install

  1. 1

    Double-click Install Storefront.command.

    If macOS says it can't be opened (Apple could not verify…): click Done, open System Settings → Privacy & Security, scroll down and click Open Anyway, then double-click the installer again.

    Or open Terminal, type bash followed by a space, drag Install Storefront.command into the Terminal window, and press Return.

  2. 2

    The installer moves Storefront into Applications and opens it.

Prefer to do it by hand? Drag Storefront into Applications and open it. The first time, macOS blocks it: go to System Settings → Privacy & Security and click Open Anyway.

Using Storefront

  • Click the striped awning in the menu bar. A red dot on it means updates are ready: click Update, or Update All.
  • Open Storefront… shows every app. Click one to see what it does, screenshots and what's new, then Install. Apps you install here open straight away, with no Open Anyway step.
  • How to use … on an app's page opens its Read Me, laid out with headings and steps. Plain Text opens the file that comes in its zip.
  • Storefront checks for updates when it starts, when your Mac wakes, and every six hours, and tells you when there are some. Turn that off in Settings › General.
  • Got an idea, or found something wrong? Every app's page has Send feedback at the bottom. It's private and anonymous: only the maker of these apps reads it, and your name and sign-in aren't sent. Send as many as you like.
  • SSIS staff: Settings › Account › Sign In with SSIS shows the apps that only work at school, on their own SSIS page.

Good to know

  • Storefront updates itself: Storefront Settings › General › Check for Storefront Updates.
  • To uninstall: quit Storefront from its menu and drag it from Applications to the Trash. Apps it installed stay.
  • Storefront is free and open source. It isn't from the App Store and isn't notarized by Apple, which is why macOS asks you to confirm it the first time.
