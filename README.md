# store.explainsims.com

The catalogue, update feeds and web page for Storefront and the Mac apps it offers. Everything here is generated by
`storefront-publish` (in the Storefront project); edit the app descriptions in Storefront's `Store/apps.json`, not
here. The app downloads are this repo's releases.

Apps only for SSIS staff aren't here at all: they live in protected storage and appear only after an SSIS sign-in.
