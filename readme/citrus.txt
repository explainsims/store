CITRUS 🍋
A free file converter that lives in your Mac's menu bar.

Drag a file, hold Shift, and a wheel of formats appears under the pointer.
Drop the file on a format and the converted copy appears next to the original.
Citrus converts images (camera RAW and Photoshop too), documents (LaTeX,
Markdown and Jupyter notebooks too), spreadsheets, audio (DSD and MIDI too),
video, archives and subtitles.


WHAT'S IN THIS FOLDER

  Citrus.app               the app
  Install Citrus.command   sets everything up (run this)
  Read Me.txt              this file


BEFORE YOU START

  • An Apple Silicon Mac (M1 or later) running macOS 14 Sonoma or newer.
  • An internet connection and a few GB of free space for the tools.
  • Your Mac password. Allow 10–20 minutes the first time.


INSTALL

  1. Double-click "Install Citrus.command".

     If macOS says it can't be opened ("unidentified developer" or
     "Apple could not verify…"): click Done, open System Settings →
     Privacy & Security, scroll down and click "Open Anyway", then
     double-click the installer again.

     Or open Terminal, type  bash  followed by a space, drag
     "Install Citrus.command" into the Terminal window, and press Return.

  2. Follow the prompts in the Terminal window. The installer:
       • installs Homebrew if needed (the standard free installer for Mac tools)
       • installs ffmpeg, WebP tools, ExifTool, pngquant, pandoc, Java and
         LibreOffice (anything already installed is skipped)
       • copies Citrus into Applications and opens it

  3. Look for the lemon in the menu bar, on a small green square.


USING CITRUS

  • Start dragging a file, then hold a key (before or during the drag):
        Shift     Convert wheel (JPG, PDF, MP3, DOCX …)
        Command   Tools:
                    images  Medium (1280 px), Small (640 px), favicon set,
                            compress, rotate, remove background,
                            copy text (reads text in the picture), strip metadata
                    PDFs    split (or merge several), compress, rotate,
                            strip metadata, copy text
                    archives extract
        Control   Actions (view metadata)
    Drop the file on a segment. Release elsewhere or press Esc to cancel.

  • The common formats are on the wheel. The rest are under More: move
    onto More and a second ring opens around the wheel, with formats such
    as GIF, ICNS (Mac icon), ICO, PSD and SVG for pictures, or Apple
    Lossless, M4B (audiobook) and MP4 for sound. SVG traces a picture's
    shapes into a drawing that stays sharp at any size. MP4 from a song
    makes a video with its cover art as the picture.

  • Settings for one conversion: drop the file on the middle of the wheel
    (or use "Convert Files…"), then right-click a format. Choose the
    quality, size, bitrate, sample rate and so on, then click Convert.
    Tick "Use these every time" to keep them.

  • Or choose "Convert Files…" from the lemon menu.

  • Converted files are saved next to the original and never overwrite
    anything; an existing name gets " 2", " 3" and so on. Multi-page
    documents saved as JPG or PNG go into a folder of page images.

  • A file with the wrong ending (say, an iPhone photo named .jpg that is
    really HEIC) is read as what it really is. The wheel says so under
    the file's name.

  • Sound keeps its quality: 24-bit files stay 24-bit, DSD becomes 88.2 kHz
    24-bit, and MIDI files are played with the Mac's own instruments.

  • Lemon menu → Settings… lets you change the keys, turn on Launch at
    Login, set image quality, and see every supported format (Compatibility).
    Untick "Colour icon in the menu bar" for a black-and-white lemon like
    the menu bar's other icons.


GOOD TO KNOW

  • Saving as PAGES uses Apple's free Pages app (from the App Store). The
    first time, macOS asks whether Citrus may control Pages: click OK.
    No other permissions are needed.

  • To update: choose Check for Updates… from the lemon menu (Citrus also
    checks once a day). Or unzip a newer copy and run its installer: it
    replaces the old Citrus and skips tools that are already installed.

  • To uninstall: choose Quit Citrus from the lemon menu, then drag
    Citrus from Applications to the Trash. The tools stay installed; to
    remove them too, run this in Terminal:
        brew uninstall ffmpeg webp exiftool pngquant pandoc openjdk && brew uninstall --cask libreoffice
